## Learning Philosophy

The goal is not to memorize hundreds of commands. The central skill is understanding how commands, arguments, options, paths, permissions, processes, pipes, redirection, environment variables and exit statuses interact.

## Practice Safely

Use a disposable Linux VM, container, WSL distribution, or test machine for experiments. Verify paths before destructive commands and avoid recursive permission/ownership changes on system directories.
