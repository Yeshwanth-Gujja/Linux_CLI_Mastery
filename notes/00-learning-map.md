## Skill progression

### Level 1 — Operate

`pwd` → `ls` → `cd` → `mkdir` → `touch` → `cp` → `mv` → `rm` → `cat` → `less`

### Level 2 — Investigate

`find` → `grep` → `file` → `stat` → `head` → `tail` → `sort` → `uniq` → `wc`

### Level 3 — Compose

Pipes → redirection → command substitution → quoting → exit status → `xargs` → `sed` → `awk`

### Level 4 — Administer

Permissions → ownership → users/groups → processes → signals → services → logs → packages → storage

### Level 5 — Operate remotely

Networking → DNS → sockets → SSH → SCP → rsync → HTTP/API inspection

### Level 6 — Automate

Bash variables → parameters → conditions → loops → functions → safe scripting → scheduling

### Level 7 — Troubleshoot

Identify → inspect → isolate → verify → read logs → test dependencies → fix → re-test → document

## How to study each topic

For every command, learn four things:

1. **What problem does it solve?**
2. **What input does it consume?**
3. **What output/status does it produce?**
4. **How can it be safely combined with other commands?**

Do not optimize for memorizing hundreds of flags. Build the mental model first, then use `man`, `--help`, and examples as reference tools.
